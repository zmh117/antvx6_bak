## Why

当前流程容器虽然有字段和面板入口，但没有达到建模体验要求：它应该像泳道一样是画布上的可视框，用户可以把 BPMN 元素实时拖入、拖出，并立即看到内部元素与连线结构。这个能力是后续让 Agent 准确理解子流程、生成 MES/Web 流程用例的前提。

## What Changes

- 将流程容器交互定义为可嵌入的画布框，而不是仅靠属性字段表达。
- 支持用户把 Task、Event、Gateway、Data 等 BPMN 节点实时拖入流程容器，容器内部立即显示这些元素。
- 支持用户把容器内部节点实时拖出到泳道顶层，节点恢复为普通泳道内元素。
- 支持容器内部节点正常连线，并允许容器内部节点连接到容器外部节点。
- 移动流程容器时，内部节点和相关连线在视觉上随容器移动，并保持稳定的相对位置。
- 保存、增量变更、协作同步、历史恢复、泳道组件模板和 Agent context 都保留容器父子关系。
- 不删除 BPMN 节点本身和 BPMN 工具箱；本变更只增强流程容器的画布交互和结构化表达。

## Capabilities

### New Capabilities

- `business-flow-process-container-interaction`: 定义业务流程图中的流程容器作为可视嵌入框的拖入、拖出、内部显示、连线、持久化和 Agent context 行为。

### Modified Capabilities

- 无。

## Impact

- 前端业务流程编辑器：流程容器节点渲染、拖拽命中检测、X6 parent/child 嵌入关系、边刷新和选择面板状态。
- 泳道组件编辑器：组件模板中的流程容器嵌入关系、拖入拖出和发布后实例化。
- 业务流程数据模型：节点 `containerNodeKey` 或等价父容器字段的读写、坐标语义和校验。
- 协作与保存链路：增量 ops、Yjs 文档、materialize、历史快照和恢复。
- Agent context：输出容器层级、内部节点列表、跨容器边界连线和质量问题。
